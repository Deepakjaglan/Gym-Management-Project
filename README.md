# 💪 Gym Management System (Django Project)

A simple and beginner-friendly **Gym Management System** built using **Python, Django, HTML, CSS, Bootstrap, and SQLite3**. This project helps gym owners manage members, trainers, attendance, and payments from one dashboard.

## 🚀 Features

* 🏠 Dashboard with total statistics
* 👤 Add, Update, Delete Gym Members
* 🏋️ Add and Manage Trainers
* 📅 Mark Daily Attendance
* 💳 Add and Track Member Payments
* 🔍 Search Members, Trainers, Attendance, and Payments
* ✅ Pending / Paid Payment Status
* 📱 Responsive Bootstrap UI
* 🎨 Professional Gym Theme Design

## 🛠️ Technologies Used

* Python 3
* Django
* HTML5
* CSS3
* Bootstrap 5
* SQLite3
